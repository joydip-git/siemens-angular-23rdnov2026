component unit testing:
---------------------------
TestBed -> context or environment created for angular assets unit testing
Configures and initializes environment for unit testing and provides methods for creating components and services in unit tests.

TestBed is the primary api for writing unit tests for Angular applications and libraries.

[code + template] -> ComponentFixture<T>: Fixture for debugging and testing a component.

DebugElment -> The DebugElement associated with the root element of this component.
 nativeElement

By -> Predicates for use with DebugElement's query functions.(@angular/platform-browser)

detectChanges() method of ComponentFixture<T> => Trigger a change detection cycle for the component.

HttpTestingController: Controller to be injected into tests, that allows for mocking and flushing of requests.

expectOne(): Expect that a single request has been made which matches the given URL, and return its mock.
