routes: [@angular/router]
------------------------------
Client-side routing: dynamically pulling a component and rebderng on the single page at the client side

http://localhost:4200/home		=> Home [http://localhost:4200 -> http://localhost:4200/home]


http://localhost:4200/products 		=> ProductContainer -> [ ProductList + FilterProduct ]
http://localhost:4200/products/view/:x 	=> ProductDetails
http://localhost:4200/products/view/1   => {x:'1'}
http://localhost:4200/products/edit/:y 	=> EditProduct
http://localhost:4200/products/add 	=> AddProduct

**					=> PageNotFound

ActivatedRoute -> a built-in service class [ an object to store current navigation information]

RouterState -> a built-in service class to store the current state of router (collection of ActvitatedRoute objects]


const provideRouter = (routes:Routes)=>{
	provide:'',
	useFactory: ()=>{
		return new Router(routes)
	}
}

RouterOutlet: Acts as a placeholder that Angular dynamically fills based on the current router state. (<router-outlet></router-outlet>)


RouterLink: When applied to an element in a template, makes that element a link that initiates navigation to a route. Navigation opens one or more routed components in one or more <router-outlet> locations on the page. This is an ATTRIBUTE DIRECTIVE

routeLink -> string (complete url) or an array of strings (url fragments)
